# GitHub Web: roteiro simples

Todo o procedimento utiliza apenas o navegador.

## 1. Criar o repositório

1. Entre em https://github.com/new
2. Nome: `indices-republica-dados`
3. Descrição: `Projeto Java simples para apresentar índices da base tratada`
4. Escolha Public ou Private
5. Marque Add a README file
6. Clique em Create repository

## 2. Enviar o projeto

1. Abra o repositório
2. Clique em Add file
3. Clique em Upload files
4. Arraste os arquivos do projeto
5. Mensagem: `feat: adiciona sistema Java de índices`
6. Clique em Commit changes

## 3. Fazer uma alteração pela tela do GitHub

1. Abra `README.md`
2. Clique no lápis para editar
3. Acrescente a conclusão da equipe
4. Clique em Commit changes
5. Mensagem: `docs: adiciona conclusão da análise`

## 4. Criar versões simples

- v1.0.0: menu e candidato
- v1.1.0: satisfação média
- v1.2.0: Saúde e conclusão

Para registrar uma versão:

1. Abra Releases na página do repositório
2. Clique em Draft a new release
3. Em Choose a tag, digite `v1.2.0`
4. Clique em Create new tag
5. Título: `Versão 1.2.0 - resultados completos`
6. Descrição: `Inclui candidato, satisfação, Saúde e conclusão`
7. Clique em Publish release

## 5. Evidências para entrega

- Link do repositório
- Tela da lista de commits
- Tela da Release v1.2.0
- Execução do menu mostrando a conclusão
