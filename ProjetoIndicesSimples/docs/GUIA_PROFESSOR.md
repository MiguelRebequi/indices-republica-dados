# Guia rápido do professor

## Demonstração sugerida

1. Explique que a turma já tratou a base e encontrou os resultados.
2. Mostre as fórmulas simples usadas antes do Java.
3. Abra `ResultadoIndices.java` e identifique atributos e métodos.
4. Abra `SistemaIndices.java` e explique o menu.
5. Execute o programa, escolha 6 e depois 5.
6. Crie o repositório pelo navegador.
7. Envie os arquivos e faça o primeiro commit.
8. Edite o README pela tela do GitHub e faça outro commit.
9. Publique a Release v1.2.0.

## Ponto principal da aula

O código recebe e exibe resultados já calculados. Ele não calcula percentuais
nem médias. A orientação a objetos organiza os valores. O GitHub registra as
alterações e identifica uma versão que pode ser apresentada novamente.
